# S.P.R.S. - Expediente Digital Penitenciario (EDP) Dashboard

Este repositorio contiene la interfaz táctica del **Expediente Digital Penitenciario** para el Servicio Penitenciario de CABA.

## 🚀 Características
*   **Interfaz Táctica**: Diseño oscuro optimizado para monitoreo y gestión de internos.
*   **Línea de Tiempo**: Visualización de eventos operacionales.
*   **Progresividad Judicial**: Gestión de fases del Plan de Vida (Observación, Tratamiento, Prueba).
*   **Módulos Integrados**: Salud, Educación, Trabajo y Seguridad.

## 🛠️ Tecnologías
*   HTML5 / CSS3 (Vanilla)
*   JavaScript (ES6+)
*   Google Fonts (Bebas Neue & Inter)

## 📦 Instalación
1. Clona el repositorio.
2. Abre `index.html` en tu navegador.
